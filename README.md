# Laravel Template

Простой шаблон проекта на Laravel, готовый к быстрому старту и дальнейшей разработке.

## О проекте

Этот репозиторий содержит готовую структуру Laravel-приложения, включая:
- базовую конфигурацию `composer` и `package.json`
- стартовый шаблон frontend-сборки
- готовую структуру директорий `app`, `config`, `database`, `resources`, `routes`
- базовые тесты на Pest и PHPUnit

Проект ориентирован на быстрое развёртывание и удобную доработку под разные задачи.

## Быстрый старт

Перейдите в директорию `laravel` и установите зависимости:

```bash
cd laravel
composer install
npm install
```

Скопируйте пример файла окружения и сгенерируйте ключ приложения:

```bash
cp .env.example .env
php artisan key:generate
```

Если вы используете Docker, настройте контейнеры отдельно — проект подготовлен для стандартного Laravel-окружения.

## Запуск

Запустите локальный сервер:

```bash
php artisan serve
```

По умолчанию приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## Структура проекта

- `app/` — приложение, контроллеры, модели и логика
- `config/` — настройки Laravel
- `database/` — миграции, сиды, фабрики
- `public/` — точка входа веб-приложения
- `resources/` — шаблоны, стили и скрипты
- `routes/` — маршруты приложения
- `tests/` — автоматические тесты

## Тестирование

Запустите тесты с помощью Pest или PHPUnit:

```bash
./vendor/bin/pest
# или
./vendor/bin/phpunit
```

## Полезные команды

```bash
php artisan migrate
php artisan migrate:fresh --seed
npm run dev
npm run build
```
